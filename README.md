# 🕵️ Telegram Spy Bot

Мой первый большой проект на Python.

Это Telegram-бот для игры **«Шпион»**, который я создаю, чтобы изучать программирование и разработку Telegram-ботов.

## Возможности

- 🎮 Создание новой игры
- 🕵️ Выбор количества шпионов
- 📂 Встроенные темы
- ➕ Добавление своих тем
- 🗑️ Удаление пользовательских тем
- 🌪️ Режим хаоса

## Технологии

- Python
- pyTelegramBotAPI (Telebot)
- JSON

## Запуск

1. Установить зависимости

```bash
pip install pyTelegramBotAPI

```

2. Вставить свой токен Telegram-бота.

3. Запустить

```bash
python main.py
```
