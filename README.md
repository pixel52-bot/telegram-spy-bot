# 🕵️‍♂️ Telegram Spy Game Bot

Увлекательная пошаговая игра **«Шпион»** для компаний и вечеринок прямо в Telegram! Передавайте телефон по кругу, узнавайте секретные роли и вычисляйте шпионов среди мирных жителей.

- 👥 Поддержка от **3 до 10 игроков**.
